## 🍪 Cookie-пранк

Отдельная страница `cookie.html` — **фейковый cookie-баннер** в стиле GitHub Dark. При клике на кнопку **«Принять всё»** или **«Настроить»** → **чёрный экран на 0.4 сек** → **видео-скример на весь экран**.

[![🍪 ОТКРЫТЬ COOKIE-ПРАНК](https://img.shields.io/badge/🍪_ОТКРЫТЬ_COOKIE--ПРАНК-cookie.html-00d68f?style=for-the-badge&labelColor=0a0a14)](https://shuto1337.github.io/tprank/cookie.html)

**Ссылка:** `https://shuto1337.github.io/tprank/cookie.html`

### Как это работает

1. **При заходе** — открывается фейковый cookie-баннер (тёмная тема, как у настоящих сайтов).
2. **Видео предзагружается** — пока пользователь читает баннер, видео качается в фоне.
3. **Клик по кнопке** → **чёрный экран на 0.4 сек** → **видео-скример на весь экран**.
4. **Никакого нативного плеера iOS** — видео растягивается через `object-fit: fill`.
5. **Ссылки** «Политика конфиденциальности» и «Условия использования» — ведут на `tretiy1337.ru`.

## 🎬 Видео-пранк

Отдельный пранк `mell.html` — **при заходе показывается реалистичная страница ошибки GitHub Pages**, а при клике открывается видео на весь экран.

[![🎬 СМОТРЕТЬ ВИДЕО-ПРАНК](https://img.shields.io/badge/🎬_СМОТРЕТЬ_ВИДЕО--ПРАНК-mell.html-ffcc00?style=for-the-badge&labelColor=0a0a14)](https://shuto1337.github.io/tprank/mell.html)

**Ссылка:** `https://shuto1337.github.io/tprank/mell.html`

### Как это работает

1. **При заходе** — реалистичная **404** от GitHub Pages:
   - Большой 404.
   - Заголовок **File not found**.
   - Текст про `index.html` и `file permissions`.
   - Футер: GitHub · Status · Docs · Contact · Pricing · API · Training · Blog · About.
   - Зелёный бейдж **nginx/1.18.0** в углу.

2. **Клик в любом месте** → видео в fullscreen.

## 🎨 Кастомные пранки

Теперь ты можешь **создавать свои пранки** — с любой картинкой, любым звуком и своей уникальной ссылкой.

[![⚡ ОТКРЫТЬ ГЕНЕРАТОР](https://img.shields.io/badge/⚡_ОТКРЫТЬ_ГЕНЕРАТОР-gen.html-ff6600?style=for-the-badge&labelColor=0a0a14)](https://shuto1337.github.io/tprank/gen.html)

### Как это работает

| Шаг | Что делать |
|:---:|:---|
| 1️⃣ | Открой [генератор](https://shuto1337.github.io/tprank/gen.html) |
| 2️⃣ | Введи название пранка |
| 3️⃣ | Загрузи картинку (автоматически уходит на ImgBB) |
| 4️⃣ | Вставь прямую ссылку на **звук** (mp3) |
| 5️⃣ | Выбери, что делает кнопка **«Заглушить»** |
| 6️⃣ | Нажми **«Создать пранк»** |
| 7️⃣ | Получи свою ссылку |
| 8️⃣ | Запиши её на NFC-метку или отправь другу |

### Что можно настроить

- **Картинку** — любая, до 32 МБ (JPG, PNG, GIF, WebP).
- **Звук** — mp3, прямая ссылка.
- **Кнопку «Заглушить»**:
  - 🔇 **Заглушает звук** — останавливает аудио
  - 🔗 **Открывает ссылку** — в новой вкладке
  - 🔇🔗 **И то, и другое** — и останавливает, и открывает
  - ❌ **Ничего не делает** — просто исчезает

## 🎵 Как получить прямую ссылку на звук

### 🥇 Способ 1 — myinstants.com

| Шаги | Что получишь |
|:---|:---|
| 1. Открой [myinstants.com](https://www.myinstants.com/) | `https://www.myinstants.com/media/sounds/xxx.mp3` |
| 2. Найди нужный звук | |
| 3. **Нажми по названию звука** (обычный клик) | |
| 4. Откроется страница с кнопкой **«Скачать mp3»** | |
| 5. **Правый клик по кнопке** → **«Копировать ссылку»** | |
| 6. Готово! | |

> ⚠️ Нужна именно **прямая** ссылка (заканчивается на `.mp3`)

### 🥈 Способ 2 — любой файлохостинг

| Шаги | Что получишь |
|:---|:---|
| 1. Загрузи mp3 на хостинг: [Catbox](https://catbox.moe/), [0x0.st](https://0x0.st/), [Litterbox](https://litterbox.catbox.moe/), [tmpfiles](https://tmpfiles.org/) | `https://files.catbox.moe/xxx.mp3` |
| 2. После загрузки появится страница с файлом | |
| 3. **Правый клик по «Скачать» (Download)** | |
| 4. **«Копировать ссылку»** | |

> ⚠️ Ссылка на страницу (без расширения файла) не подойдёт

## 📡 Как сделать NFC-метку

| Шаг | Действие | Эмодзи |
|:---:|:---|:---:|
| **1** | Купи NFC-метку (NTAG213, NTAG215, NTAG216) | 🛒 |
| **2** | Скачай приложение **NFC Tools** (Android/iOS) | 📱 |
| **3** | Открой приложение → вкладка **WRITE** | ✍️ |
| **4** | **Add a record** → **URL** | ➕ |
| **5** | Вставь ссылку на нужный пранк | 🔗 |
| **6** | Нажми **Write** → приложи метку к телефону | 📶 |
| **7** | Готово! Прикладывай телефон → открывается страница | ✅ |

## ⚠️ Важно знать

| ⚠️ Проблема | 💡 Решение |
|:---|:---|
| **Автовоспроизведение заблокировано** | Звук пойдёт только после тапа. Это защита браузеров |
| **iOS Safari и беззвучный режим** | На iPhone с «Без звука» звук не пойдёт |
| **Ссылки на звуки** | Могут пропасть. Надёжнее залить на GitHub Releases |
| **Ссылки на картинки** | С `gstatic.com` могут блокироваться. Лучше на GitHub Pages |
| **Видео с русскими буквами** | Работает, но лучше переименовать в `video.mp4` |
| **Формат видео** | Только MP4 (H.264). MKV, AVI, HEVC не проигрываются |

## ❓ FAQ

<details><summary><b>🔊 Почему звук не играет сразу?</b></summary>Браузеры блокируют автовоспроизведение без действия пользователя. Это защита от спама. Звук пойдёт только после тапа по картинке.</details>

<details><summary><b>📱 Работает ли на iPhone?</b></summary>Да, но с оговоркой: если у тебя включён беззвучный режим — звук не пойдёт. Это ограничение iOS Safari, обойти нельзя.</details>

<details><summary><b>🍪 Что такое cookie-пранк?</b></summary>Это страница <code>cookie.html</code> — фейковый cookie-баннер. При клике на «Принять всё» или «Настроить» → чёрный экран 0.4 сек → видео-скример на весь экран.<br><br>[![🍪 COOKIE-ПРАНК](https://img.shields.io/badge/🍪_COOKIE--ПРАНК-cookie.html-00d68f?style=for-the-badge&labelColor=0a0a14)](https://shuto1337.github.io/tprank/cookie.html)</details>

<details><summary><b>🎬 Что такое видео-пранк?</b></summary>Это страница <code>mell.html</code> — при заходе показывается реалистичная ошибка GitHub Pages (404), а при клике открывается видео в fullscreen.<br><br>[![🎬 ВИДЕО-ПРАНК](https://img.shields.io/badge/🎬_ВИДЕО--ПРАНК-mell.html-ffcc00?style=for-the-badge&labelColor=0a0a14)](https://shuto1337.github.io/tprank/mell.html)</details>

<details><summary><b>📡 Какие NFC-метки подходят?</b></summary>Любые: NTAG213, NTAG215, NTAG216. Главное — чтобы они поддерживали запись URL.</details>

<details><summary><b>🔗 Можно ли использовать свою ссылку?</b></summary>Да. В генераторе ты получаешь уникальную ссылку вида:<br><br><code>https://shuto1337.github.io/tprank/p.html?id=abc12345</code><br><br>Её можно записать на NFC или отправить другу.</details>

<details><summary><b>🔇 Что делает кнопка «Заглушить»?</b></summary>Настраивается при создании пранка:<br><br>• 🔇 <b>Заглушает звук</b> — останавливает аудио<br>• 🔗 <b>Открывает ссылку</b> — в новой вкладке<br>• 🔇🔗 <b>И то, и другое</b> — и останавливает, и открывает<br>• ❌ <b>Ничего не делает</b> — просто исчезает</details>

<details><summary><b>🖼 Какие картинки подходят?</b></summary>Формат: <b>JPG, PNG, GIF, WebP</b>. Размер: до <b>32 МБ</b>. Лучше квадратные (например 800×800).</details>

<details><summary><b>💾 Где хранятся пранки?</b></summary>В Firebase (ветка <code>custom_pranks</code>). Каждый пранк — это запись с названием, картинкой, ссылкой на звук и настройками кнопки.</details>

<details><summary><b>📹 Видео не играет — что делать?</b></summary>Проверь:<br>1. Формат видео — должен быть <b>MP4 (H.264)</b>.<br>2. Ссылка прямая — открывается в браузере и играет.<br>3. Размер — до <b>100 МБ</b> для GitHub Pages.<br>4. Имя файла — лучше без русских букв и пробелов (<code>video.mp4</code>).</details>
