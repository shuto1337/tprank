# tprank

Коллекция пранк-страниц для NFC-меток.

Автор: [tretiy1337.ru](https://tretiy1337.ru)

## Что это

Набор HTML-страниц, каждая из которых:
- Показывает заблюренную картинку на фоне
- Имеет кнопку по центру (та же картинка, но чёткая)
- При клике играет громкий звук

Идея: записываешь ссылку на NFC-метку, клеишь её где-нибудь в общественном месте. Человек прикладывает телефон → открывается страница → тапает по кнопке → играет громкий звук. Все вокруг слышат.

## Как работает

1. **Открытие страницы.** Загружается HTML с двумя картинками: одна размытая на фоне (`filter: blur(20px)`), вторая чёткая — это кнопка по центру.
2. **Клик по кнопке.** Срабатывает JavaScript: если звук на паузе — играет, если играет — ставится на паузу.
3. **Звук.** MP3-файл подтягивается с внешнего источника (myinstants.com) или с GitHub Releases.
4. **Автовоспроизведение.** Браузеры блокируют автозапуск звука без жеста пользователя. Поэтому звук включается только после клика — это защита Chrome, Safari, Firefox.

## Как сделать NFC-метку

1. Купи NFC-метку (NTAG213, NTAG215, NTAG216 — любые).
2. Скачай приложение для записи NFC: **NFC Tools** (Android/iOS).
3. Открой приложение → вкладка **WRITE** → **Add a record** → **URL**.
4. Вставь ссылку на нужный пранк (из таблицы выше).
5. Нажми **Write** → приложи метку к телефону.
6. Готово. Теперь при прикладывании телефона к метке — откроется страница с пранком.
