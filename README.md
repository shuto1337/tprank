# tprank

Коллекция пранк-страниц для NFC-меток.

Автор: [tretiy1337.ru](https://tretiy1337.ru)

## Что это

Набор HTML-страниц, каждая из которых:
- Показывает заблюренную картинку на фоне
- Имеет большую кнопку по центру (та же картинка, но чёткая)
- При клике играет громкий звук

**Идея:** записываешь ссылку на NFC-метку, клеишь её где-нибудь в общественном месте. Человек прикладывает телефон → открывается страница → тапает по кнопке → играет громкий звук. Все вокруг слышат.

## ⚙️ Как это работает

1. `index.html` читает список пранков из базы данных и показывает их карточками.
2. Каждая карточка — картинка, название, кнопка «Открыть».
3. Кнопка ведёт на страницу пранка.

---

## 📱 Как сделать NFC-метку

1. Купи NFC-метку (NTAG213, NTAG215, NTAG216 — любые).
2. Скачай приложение для записи NFC: **NFC Tools** (Android/iOS).
3. Открой приложение → вкладка **WRITE** → **Add a record** → **URL**.
4. Вставь ссылку на нужный пранк.
5. Нажми **Write** → приложи метку к телефону.
6. Готово. При прикладывании телефона к метке — откроется страница.

## ⚠️ Важно

- **Автовоспроизведение заблокировано.** Звук пойдёт только после тапа по кнопке. Это не баг — это защита браузеров.
- **iOS Safari и беззвучный режим.** На iPhone с включённым переключателем «Без звука» звук не пойдёт. Ничего не сделать.
- **Ссылки на звуки.** Если звуки лежат на внешних сайтах — они могут пропасть. Надёжнее залить на GitHub Releases или GitHub Pages.
- **Ссылки на картинки.** Картинки с `gstatic.com` (гугл) могут блокировать прямые ссылки. Надёжнее залить на GitHub Pages.
